# Organization Module — ကုမ္ပဏီဖွဲ့စည်းပုံ

> Customer Presentation အတွက် Module တစ်ခုချင်းစီ ရှင်းလင်းချက်။ အနှစ်ချုပ်ကို [CLIENT-MODULE-GUIDE.md](../CLIENT-MODULE-GUIDE.md) တွင် ကြည့်ပါ။

## 1. ဘာကြောင့် လိုအပ်သလဲ

Organization သည် HRMS တစ်ခုလုံး၏ **အခြေခံ** ဖြစ်သည်။ ဝန်ထမ်းတစ်ဦးကို ထည့်ရာတွင် ဘယ်ကုမ္ပဏီ၊ ဘယ်ဘဏ်ခွဲ၊ ဘယ်ဌာန၊ ဘယ်ရာထူး၊ ဘယ် Grade ဆိုတာ ရွေးရမည်။ ထို့ကြောင့် ဤ Module ကို **အရင်ဆုံး Setup လုပ်** ရသည်။

## 2. ဖွဲ့စည်းပုံ အဆင့်ဆင့်

```
Company (ကုမ္ပဏီ)
 └─ Branch (ဘဏ်ခွဲ / ရုံးခွဲ)
     └─ Department (ဌာန)
         └─ Section (ဌာနခွဲ)
             └─ Position (ရာထူး)      Job Grade ← ရာထူးအဆင့် + လစာအကွာအဝေး
```

## 3. Screen တစ်ခုချင်းစီ

| Screen | ရည်ရွယ်ချက် | ဥပမာ |
|---|---|---|
| **Companies** | ကုမ္ပဏီ / Legal Entity များ | APEX Group |
| **Branches** | ကုမ္ပဏီအောက်ရှိ ရုံးခွဲများ | ရန်ကုန်ရုံးချုပ်၊ မန္တလေးရုံးခွဲ |
| **Departments** | ဘဏ်ခွဲတစ်ခုအောက်ရှိ ဌာနများ | HR, Finance, IT |
| **Sections** | ဌာနအောက်ရှိ အဖွဲ့ငယ်များ | IT → Development, Support |
| **Positions** | ရာထူးအမည်များ | HR Officer, Software Engineer |
| **Job Grades** | ရာထူးအဆင့်နှင့် **လစာအနည်းဆုံး–အများဆုံး (Salary Band)** | Grade 3: 600,000 – 900,000 |
| **Reporting Structure** | ဘယ်သူက ဘယ်သူ့ကို Report လုပ်သည်ကို ကြည့်ရန် | Manager → အဖွဲ့ဝင်များ |

(ဥပမာ ဂဏန်းများသည် ရှင်းပြရန်သာ — Demo ဒေတာနှင့် မတူနိုင်သည်။)

## 4. စနစ်က ကာကွယ်ပေးသော စည်းမျဉ်းများ

- **ဖွဲ့စည်းပုံ မှန်ကန်မှု စစ်ဆေးသည်:** ဌာနသည် ကိုယ့်ကုမ္ပဏီ၏ ဘဏ်ခွဲအောက်တွင်သာ ရှိနိုင်သည်။
- **ဖျက်ခြင်းကို တားသည်:** ဝန်ထမ်း/အခြား Record များက ကိုးကားထားသော အချက်အလက်ကို ဖျက်၍မရ — **Deactivate** သာ လုပ်နိုင်သည်။ ဒေတာ ပျက်စီးခြင်းမှ ကာကွယ်သည်။
- **Job Grade ↔ Payroll:** ဝန်ထမ်း၏ Basic လစာသည် Grade ၏ Salary Band အတွင်း ရှိရမည် (Payroll Module တွင် အသုံးချ)။
- **Job Grade ↔ Leave:** ခွင့် Policy ကို Grade အလိုက် သတ်မှတ်နိုင်သည်။

## 5. အခြား Module များနှင့် ချိတ်ဆက်မှု

| Module | Organization ကို ဘယ်လို သုံးသလဲ |
|---|---|
| Employees | ကုမ္ပဏီ / ဘဏ်ခွဲ / ဌာန / ရာထူး / Grade ရွေးရန် |
| Attendance | ဌာနအလိုက် တက်ရောက်မှု Chart |
| Leave | Grade အလိုက် ခွင့် Policy |
| Payroll | Grade အလိုက် လစာအကွာအဝေး စစ်ဆေးရန် |
| Recruitment | Job Opening ကို ဌာန / ရာထူးနှင့် ချိတ်ရန် |
| Dashboard | ဌာနအလိုက် ဝန်ထမ်းခွဲခြမ်း Chart |

## 6. Customer ထံ ပြောနိုင်သော အကျိုးကျေးဇူး

1. ကုမ္ပဏီအဖွဲ့အစည်းပုံစံ (Org Chart) ကို စနစ်ထဲ တိတိကျကျ ထားနိုင်သည်။
2. Branch / Department များ ကွဲပြားသော ကုမ္ပဏီကြီးများအတွက်ပါ ရပြီး Company အများအပြား ထည့်နိုင်သည်။
3. လစာအကန့်အသတ်ကို Grade ဖြင့် ထိန်းချုပ်၍ လစာတန်ဖိုး မမှန်ကန်မှုကို ကြိုတားနိုင်သည်။
4. ဖွဲ့စည်းပုံ ပြောင်းလဲလျှင် (ဌာနအသစ်၊ ရာထူးအသစ်) ကိုယ်တိုင် ထည့်နိုင်သည်၊ Developer မလို။

## 7. Demo ပြသရန် အဆင့်များ (၂ မိနစ်)

1. Sidebar → **Organization → Companies** ဖွင့်ပြီး Company ကို ပြသည်။
2. **Departments** တွင် ဌာနအသစ်ထည့်ရန် ကြိုးစားပြီး ကိုယ့်ကုမ္ပဏီနှင့် မကိုက်သော ဘဏ်ခွဲကို ရွေးခိုင်းကာ Validation ပြသည်။
3. **Job Grades** တွင် Salary Band ကို ပြသည်။
4. **Reporting Structure** တွင် Report လမ်းကြောင်းကို ပြသည်။
5. အသုံးပြုထားသော Record ကို ဖျက်ကြည့်ပြီး "ဖျက်၍မရ၊ Deactivate လုပ်ပါ" ဟု ပြသည်။

## 8. လက်ရှိ ကန့်သတ်ချက်

- Demo ဒေတာဖြစ်ပြီး Page Reload လုပ်လျှင် မူလအတိုင်း ပြန်ဖြစ်သည် (Backend ချိတ်ပြီးမှ အမြဲသိမ်းမည်)။
- Organization အတွက် Excel Import မရှိသေး (လက်ရှိ Employees သာ)။
