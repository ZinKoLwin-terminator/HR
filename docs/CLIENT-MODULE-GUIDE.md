# APEX HRMS — Module Guide (Customer Presentation)

**Audience:** HR / business decision makers at a prospective customer. ဒီစာတမ်းကို Demo ပြသရာတွင် ကိုင်ဆောင်ရန်နှင့် Customer ထံ ပေးပို့ရန် ရေးသားထားသည်။
နည်းပညာဆိုင်ရာ အသေးစိတ်ကို [FEATURES.md](FEATURES.md) နှင့် [ARCHITECTURE.md](ARCHITECTURE.md) တွင် ကြည့်ပါ။

## 1. APEX HRMS ဆိုတာ ဘာလဲ

APEX HRMS သည် ကုမ္ပဏီတစ်ခု၏ **လူသားအရင်းအမြစ် (HR) လုပ်ငန်းစဉ်အားလုံးကို တစ်နေရာတည်းတွင် စီမံနိုင်သော စနစ်** ဖြစ်သည်။
ဝန်ထမ်းမှတ်တမ်း၊ အလုပ်ချိန်၊ ခွင့်၊ လစာတွက်ချက်မှု၊ ဝန်ထမ်းခေါ်ယူမှုတို့ကို Excel ဖိုင်များနှင့် စာရွက်များ ပြန့်ကျဲစီမံနေရခြင်းမှ ဖယ်ရှားပေးသည်။

**ဘာကြောင့် သုံးသင့်သလဲ**

| ပြဿနာ (ယခုအခြေအနေ) | APEX HRMS ဖြင့် |
|---|---|
| ဝန်ထမ်းအချက်အလက်များ Excel ဖိုင်များတွင် ပြန့်ကျဲနေသည် | ဝန်ထမ်းတစ်ဦးချင်းစီအတွက် Profile တစ်ခုတည်း၊ အချက်အလက်ကြားက ချိတ်ဆက်ထားသည် |
| ခွင့်လက်ကျန်ကို လက်ဖြင့် ရေတွက်ရသည် | Policy အလိုက် Balance ကို အလိုအလျောက် တွက်ပေးသည် |
| လစာတွက်ရာတွင် အချိန်ကုန်ပြီး အမှားများသည် | ခွင့်၊ OT၊ အလုပ်ဝင်/ထွက်ရက်ကို ချိတ်ပြီး လစာကို အလိုအလျောက် တွက်ပေးသည် |
| ခွင့်ပြုချက် (Approval) များ ပါးစပ်/စာရွက်ဖြင့် ပျောက်ဆုံးတတ်သည် | Submit → Approve/Reject အဆင့်ဆင့် Workflow ရှိသည် |
| Report ထုတ်ရန် အချိန်ကြာသည် | Dashboard တွင် KPI နှင့် Chart များ ချက်ချင်းကြည့်နိုင်သည် |

**Module များ၏ ဆက်စပ်ပုံ**

```
Organization ──► Employees ──► Attendance ──(ခွင့်ပြုပြီး OT)──┐
 (ကုမ္ပဏီဖွဲ့စည်းပုံ)  (ဝန်ထမ်း)      (အလုပ်ချိန်)  ▲                 ├──► Payroll (လစာ)
                          └──► Leave (ခွင့်) ──(လစာမဲ့ခွင့်)──┘
                                      └─ ခွင့်ပြုလျှင် Attendance ကို On Leave ပြောင်း
Recruitment (ခေါ်ယူမှု) ──► Employees        Dashboard = အားလုံးကို အကျဉ်းချုပ်ပြသည်
Settings = User / Role / Permission          Data Exchange = Excel Import / Export
```

## 2. Module တစ်ခုချင်းစီ

အသေးစိတ် Module စာမျက်နှာများ: [Organization](modules/organization.md) · [Payroll](modules/payroll.md) (ကျန် Module များကို ဆက်ရေးမည်)

### 2.1 Dashboard — ခေါင်းဆောင်များအတွက် တစ်မျက်နှာတည်း အကျဉ်းချုပ်

- **ဘာလုပ်ပေးသလဲ:** ကုမ္ပဏီ၏ လက်ရှိအခြေအနေကို Login ဝင်ပြီးချက်ချင်း မြင်ရသည်။
- **ပါဝင်သည်များ:** ဝန်ထမ်းအရေအတွက် စသော KPI Card များ၊ ဝန်ထမ်းတိုးတက်မှု / ဌာနအလိုက်ခွဲခြမ်း / တက်ရောက်မှု Trend Chart များ၊ ခွင့်ခွင့်ပြုရန် စောင့်ဆိုင်းနေသော တောင်းဆိုမှုများ၊ ရောက်လာမည့် ဖြစ်ရပ်များ၊ နောက်ဆုံး လစာတွက်ချက်မှု အကျဉ်းချုပ်၊ လတ်တလော လှုပ်ရှားမှုများ။
- **ဘယ်သူ သုံးသလဲ:** CEO / HR Manager / Department Head။
- **အကျိုးကျေးဇူး:** "ဒီလ ဘယ်နှစ်ယောက်ဆင်းတာလဲ၊ ဘယ်ခွင့်တွေ စောင့်နေလဲ" ကို Report မတောင်းဘဲ သိနိုင်သည်။

### 2.2 Organization — ကုမ္ပဏီဖွဲ့စည်းပုံ အခြေခံ

- **ဘာလုပ်ပေးသလဲ:** ကုမ္ပဏီ၏ အဆင့်ဆင့်ဖွဲ့စည်းပုံကို သတ်မှတ်သည်။ ကျန် Module အားလုံးသည် ဤအချက်အလက်ကို အခြေခံသည်။
- **ပါဝင်သည်များ:** Companies → Branches → Departments → Sections → Positions၊ Job Grades (လစာအကွာအဝေးပါ)၊ Reporting Structure (ဘယ်သူက ဘယ်သူ့ကို report လုပ်သလဲ)။
- **အရေးကြီး စည်းမျဉ်း:** ဌာနသည် ကိုယ့်ကုမ္ပဏီ၏ ဘဏ်ခွဲအောက်တွင်သာ ရှိနိုင်သည် (ဖွဲ့စည်းပုံ မှားယွင်းခြင်းကို တားသည်)။ အသုံးပြုထားသော Record ကို ဖျက်၍မရ၊ Deactivate သာ လုပ်နိုင်သည် — ဒေတာ မပျက်စီးစေရန်။
- **အကျိုးကျေးဇူး:** ဌာနအလိုက် Report၊ Approval လမ်းကြောင်း၊ လစာအကန့်အသတ်များကို မှန်ကန်စွာ ချိတ်ဆက်နိုင်သည်။

### 2.3 Employees — ဝန်ထမ်းမှတ်တမ်း

- **ဘာလုပ်ပေးသလဲ:** ဝန်ထမ်းတစ်ဦးချင်းစီ၏ အချက်အလက်အားလုံးကို တစ်နေရာတည်း သိမ်းသည်။
- **ပါဝင်သည်များ:**
  - **List:** ရှာဖွေ၊ Filter၊ စီ၊ စာမျက်နှာခွဲ ကြည့်နိုင်သည်။
  - **Add/Edit Form:** ဖုန်းနံပါတ်၊ အသက်၊ ရက်စွဲ၊ ထပ်နေခြင်း (Duplicate) စစ်ဆေးမှုပါသည်။
  - **Profile (Tab များ):** Overview, Employment, History, Documents, Salary Summary, Attendance, Leave။
  - **Documents:** ဝန်ထမ်းစာရွက်စာတမ်း စာကြည့်တိုက်။
  - **Excel Import/Export:** ဝန်ထမ်းအများအပြားကို တစ်ပြိုင်နက် ထည့်ခြင်း/ထုတ်ခြင်း။
- **အကျိုးကျေးဇူး:** ဝန်ထမ်း ၁ ဦးအတွက် "Single Source of Truth"။ ခွင့်၊ အလုပ်ဆင်း၊ လစာ မှတ်တမ်းကို Profile တွင်ပင် ကြည့်နိုင်သည်။

### 2.4 Attendance — အလုပ်ချိန်နှင့် တက်ရောက်မှု

- **ဘာလုပ်ပေးသလဲ:** ဝန်ထမ်းတက်ရောက်မှု၊ Shift၊ အချိန်ပိုဆင်း (OT) ကို စီမံသည်။ **ခွင့်ပြုပြီး OT တောင်းခံမှုများကိုသာ** လစာတွက်ချက်မှုသို့ ပေးသည် (နေ့စဉ်တက်ရောက်မှုမှတ်တမ်းကို Payroll က မဖတ်ပါ)။
- **ပါဝင်သည်များ:**
  - **Overview:** ယနေ့ / ဌာနအလိုက် တက်ရောက်မှု အခြေအနေ
  - **Check In/Out** နှင့် **Records**
  - **Late & Early:** နောက်ကျ / စောစောပြန် ချွင်းချက်စာရင်း
  - **Shifts / Shift Assignment / Work Schedules:** အလုပ်ချိန်ဇယား (အပတ်စဉ် Grid)
  - **Overtime:** OT တောင်းခံမှုနှင့် ခွင့်ပြုချက်
  - **Adjustments:** မှတ်တမ်းမှားယွင်းမှု ပြင်ဆင်ရန် တောင်းဆိုမှု (Approval ပါ)
- **အရေးကြီး စည်းမျဉ်း:** နေ့စဉ် Status (Present/Late/Absent/Leave…) ကို Shift စည်းမျဉ်း၊ အများပြည်သူ အားလပ်ရက်၊ ခွင့်ပြုပြီး ခွင့်တို့မှ အလိုအလျောက် သတ်မှတ်သည်။
- **အကျိုးကျေးဇူး:** နောက်ကျ၊ ပျက်ကွက်မှုကို ချက်ချင်းမြင်ရပြီး လစာနှုတ်ခြင်း/ OT ပေးခြင်း အငြင်းပွားမှု လျော့သည်။

### 2.5 Leave Management — ခွင့်စီမံခန့်ခွဲမှု

- **ဘာလုပ်ပေးသလဲ:** ခွင့်အမျိုးအစား၊ ခွင့်ရက်ပေးမှု၊ တောင်းဆိုမှုနှင့် ခွင့်ပြုချက်ကို စနစ်တကျ လုပ်ဆောင်သည်။
- **ပါဝင်သည်များ:**
  - **Leave Types** (နှစ်ပတ်လည်ခွင့်၊ နာမကျန်းခွင့်၊ လစာမဲ့ခွင့် စသည်)
  - **Policies:** Job Grade၊ အလုပ်သက်၊ လစဉ် စုဆောင်းမှု (Accrual) အလိုက်
  - **Balances:** လက်ကျန်ခွင့်ရက်
  - **Applications:** ခွင့်တင် → ခွင့်ပြု/ပယ်ချ Workflow နှင့် Approvals Queue
  - **Calendar:** အဖွဲ့လိုက် ခွင့်ပြက္ခဒိန်
- **အရေးကြီး စည်းမျဉ်း:** လက်ကျန်ကို Policy + Accrual + ခွင့်ပြုပြီးသော ခွင့်မှ တွက်သည်။ ခွင့်ရက်ရေတွက်ရာတွင် စနေ၊ တနင်္ဂနွေ နှင့် အားလပ်ရက်များကို ချန်လှပ်သည်။
- **အကျိုးကျေးဇူး:** ခွင့်လက်ကျန် အငြင်းပွားမှု မရှိ၊ Manager များ ခွင့်ပြုချက်ကို တစ်နေရာတည်းတွင် စီမံနိုင်သည်၊ အဖွဲ့ထဲ ဘယ်သူ မရှိမလဲ ကြိုမြင်နိုင်သည်။

### 2.6 Payroll — လစာတွက်ချက်ခြင်း

- **ဘာလုပ်ပေးသလဲ:** လစဉ်လစာကို လစာ Setup၊ ဝင်/ထွက်ရက်၊ လစာမဲ့ခွင့်၊ ခွင့်ပြုပြီး OT နှင့် အားလပ်ရက်တို့ကို ချိတ်ပြီး တွက်ချက်သည်။
- **ပါဝင်သည်များ:**
  - **Salary Components:** ဝင်ငွေ/နုတ်ငွေ အမျိုးအစား (ပုံသေ၊ Basic ၏ %, Gross ၏ %)
  - **Salary Structures:** Component အစုအဝေး
  - **Employee Salaries:** ဝန်ထမ်းအလိုက် Basic လစာ (Effective Date ဖြင့် ပြင်ဆင်မှု မှတ်တမ်း၊ Job Grade လစာအကွာအဝေးအတွင်း ရှိရမည်)
  - **Payroll Processing:** လ အလိုက် Period ဖန်တီး → **Process → Approve → Mark as Paid**
  - **Payslips:** ဝန်ထမ်းလစာစလစ် (ကြည့်/ပရင့်)
  - **History:** လအလိုက် Gross နှင့် Net နှိုင်းယှဉ်
- **တွက်ချက်ပုံ အကျဉ်း:** အလုပ်ဝင်/ထွက်လကို ရက်အလိုက် အချိုးကျ၊ OT ကို ၁.၅ ဆ၊ လစာမဲ့ခွင့်ကို နေ့ပျမ်းမျှ နုတ်၊ Net = Gross − Deductions။
- **ထိန်းချုပ်မှု:** အရင်လ မပြီးမချင်း နောက်လကို မလုပ်နိုင်၊ Payslip သည် Snapshot ဖြစ်၍ နောက်ပိုင်း Setup ပြောင်းလည်း မပြောင်း၊ Paid ပြီးလျှင် အပြီးအပိုင်ဖြစ်သည်။
- **အကျိုးကျေးဇူး:** လစာတွက်ချိန် ရက်များမှ မိနစ်ပိုင်းသို့ လျော့ကျ၊ အမှားနည်းပြီး Audit လမ်းကြောင်း ရှိသည်။

### 2.7 Recruitment — ဝန်ထမ်းခေါ်ယူမှု

- **ဘာလုပ်ပေးသလဲ:** ရာထူးဖွင့်ခြင်းမှ ရွေးချယ်ခြင်းအထိ ခေါ်ယူမှု လုပ်ငန်းစဉ်ကို ခြေရာခံသည်။
- **ပါဝင်သည်များ:**
  - **Job Openings:** Draft → Publish / On hold / Close / Reopen (လူပြည့်လျှင် Filled ဖြစ်သွားသည်)
  - **Candidates:** လျှောက်ထားသူ ဒေတာဘေ့စ် (Email မထပ်ရ)
  - **Interviews:** ဇယားဆွဲ၊ Interviewer ထပ်မအေးအောင် စစ်ဆေး၊ ရမှတ် (၁–၅) နှင့် အကြံပြုချက်
  - **Pipeline Board:** Applied → Screening → Interview → Selected / Rejected (Kanban ပုံစံ)
- **အရေးကြီး စည်းမျဉ်း:** ပယ်ချလျှင် အကြောင်းပြချက် လိုသည်၊ Selected ရန် အင်တာဗျူးပြီး "Hire" အကြံပြုချက်နှင့် လစ်လပ်နေသော နေရာ လိုသည်။
- **အကျိုးကျေးဇူး:** လျှောက်ထားသူ ဘယ်အဆင့်ရောက်နေလဲ တစ်မြင်ကွင်းတည်း မြင်ရပြီး ခေါ်ယူမှု ညီညွတ်၊ ရှင်းလင်းလာသည်။

### 2.8 Data Exchange — Excel Import / Export

- **ဘာလုပ်ပေးသလဲ:** ရှိပြီးသား Excel ဒေတာကို စနစ်ထဲ ကူးထည့်နိုင်ပြီး စာရင်းများကို Excel အဖြစ် ထုတ်နိုင်သည်။
- **အဆင့်များ:** Template ဒေါင်းလုဒ် → Upload → Column Mapping → Review → Confirm → Result။
- **ပါဝင်သည်များ:** Import History၊ အမှားအသေးစိတ်နှင့် Validation Report ဒေါင်းလုဒ်၊ စာရင်းများပေါ်တွင် Export Dialog။
- **ကာကွယ်မှု:** မှားယွင်းသော ဖိုင်၊ Header မှား၊ Excel Formula ထိုးသွင်းမှု (Formula Injection) များကို စစ်ဆေးတားဆီးသည်။
- **အခြေအနေ:** လက်ရှိ **Employees အတွက် အပြည့်အစုံ** ရှိပြီး အခြား Module များ ထပ်တိုးရန် စီစဉ်ထားသည်။
- **အကျိုးကျေးဇူး:** လက်ရှိ Excel ဒေတာကို စနစ်ပြောင်းချိန် ဝန်ထမ်းရာပေါင်းများစွာကို မိနစ်ပိုင်းတွင် ရွှေ့နိုင်သည်။

### 2.9 Settings — စနစ်ဆက်တင်နှင့် အသုံးပြုသူ စီမံခန့်ခွဲမှု

- **ဘာလုပ်ပေးသလဲ:** စနစ်ကို ကုမ္ပဏီနှင့် ကိုက်ညီအောင် ပြင်ဆင်ပြီး ဘယ်သူ ဘာလုပ်ခွင့်ရှိသည်ကို သတ်မှတ်သည်။
- **ပါဝင်သည်များ:**
  - **General:** ကုမ္ပဏီအမည်၊ ဆက်သွယ်ရန် Email၊ Time Zone၊ ရက်စွဲပုံစံ၊ ငွေကြေး၊ ဘဏ္ဍာနှစ်စတင်ရက်၊ Notification
  - **Users:** ဝန်ထမ်းတစ်ဦးနှင့် ချိတ်ထားသော Account (Active / Inactive / Locked)
  - **Roles:** HR Administrator စသည့် အခန်းကဏ္ဍများ
  - **Permissions:** Module × Action (View/Create/Edit/Delete…) Matrix
- **ကာကွယ်မှု:** ကိုယ့် Account ကိုယ် မဖျက်နိုင်/ အဆင့်မလျှော့နိုင်၊ အသုံးပြုသူရှိသော Role ကို မဖျက်နိုင်။

## 4. Customer မေးလေ့ရှိသော မေးခွန်းများ

**မေး။ ကျွန်တော်တို့ ကုမ္ပဏီ စည်းမျဉ်း (ခွင့်ရက်၊ OT နှုန်း) နှင့် ကိုက်အောင် ပြင်နိုင်ပါသလား။**
ဖြေ။ ခွင့်အမျိုးအစား၊ Policy၊ Shift၊ Salary Component များကို Setup မှ ကိုယ်တိုင် သတ်မှတ်နိုင်သည်။ ထူးခြားသော တွက်ချက်မှုများကို Customization အဖြစ် ဆွေးနွေးနိုင်သည်။

**မေး။ ဒေတာ ရှိပြီးသား Excel မှ ရွှေ့လို့ရပါသလား။**
ဖြေ။ ရသည်။ Data Exchange ၏ Import Wizard ဖြင့် ဝန်ထမ်းဒေတာကို Validation စစ်ပြီး ထည့်နိုင်သည်။

**မေး။ ကြိုက်သလောက် User ထည့်ပြီး ခွင့်ပြုချက်ခွဲလို့ ရပါသလား။**
ဖြေ။ Roles နှင့် Permissions Matrix ဖြင့် သတ်မှတ်နိုင်ရန် ဒီဇိုင်းထားသည် (အောက်ပါ အခြေအနေ ကဏ္ဍကို ကြည့်ပါ)။

**မေး။ Mobile တွင် သုံးနိုင်ပါသလား။**
ဖြေ။ Responsive Design ဖြစ်ပြီး Desktop နှင့် Mobile နှစ်မျိုးလုံးတွင် Test လုပ်ထားသည်။ Dark / Light Theme ပါသည်။

Customer ကို မမှန်သော မျှော်လင့်ချက် မပေးမိစေရန် Demo ပြသခြင်းအခါ ဤအချက်များကို ထည့်ပြောပါ။

|---|---|---|
| ဒေတာ | Sample ဒေတာ၊ Page Reload လုပ်လျှင် မူလအတိုင်း ပြန်ဖြစ် | Backend + Database ချိတ်ဆက်ရမည် ([API-INTEGRATION-PLAN.md](API-INTEGRATION-PLAN.md)) |

| Excel Import | Employees သာ | အခြား Module များ ထပ်တိုးရမည် |

> **အကြံပြုချက်:** ဤစနစ်ကို "အပြည့်အဝ ပြီးစီးသော Production ထုတ်ကုန်" အဖြစ် မရောင်းဘဲ၊ **Working Prototype / Demo** အဖြစ်ပြသပြီး Backend၊ လစာဥပဒေ၊ Security အဆင့်များကို Project Scope အဖြစ် သီးခြားသဘောတူညီမှုယူပါ။
